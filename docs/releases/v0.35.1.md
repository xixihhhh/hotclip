# HotClip v0.35.1

- 首页选择「用配方开始下一期」可打开已存栏目或导入配方。在工作台，「保存导出设置」保存出片开关，「保存整套栏目配方」同时保存品牌、分屏和选段设置。
- 音乐和水印各自显示配方要求的文件名与本机绑定的文件名。可以只更换其中一项。取消选择会保留原有绑定；本机文件被移动或无法读取时，界面会指出需要处理的项目，并将键盘焦点移到对应按钮。

- Open **Start the next episode with a recipe** on the import screen to use or import a recipe. The workbench now distinguishes **Save export settings** from **Save full episode recipe**.
- Music and watermark rows show the recipe file and the actual bound file. Change or cancel either independently. Missing files are identified by asset, with keyboard focus moved to the control that can fix the issue.
