# HotClip v0.22.0 — 画面该救才救，正常素材一帧不乱动

这一版加入完全本地、无需新模型的智能画面校正。它默认关闭，只在最终保留画面的测量证据充分且明显偏暗、发灰、过曝或过饱和时做有硬上限的轻调整。

- 片段级实测：复用既有 4fps Tier-0 解码，保留亮度低位、均值、高位和饱和度；跳剪、多片段拼接只统计最终留下的源时间，不拿整场平均值盲调每条成片。
- 克制有上限：亮度、反差、饱和度与 gamma 都有窄幅硬上限；正常素材不加滤镜，接近黑白的素材不会被强行增艳，证据不足直接保持原样。
- 全渲染路径一致：连续剪、跳剪和高潮前置分别使用对应窗口的方案；校正位于裁切/缩放之后、字幕和水印之前，避免文字与品牌色被调色。
- 桌面与 Agent 同能力：出片面板和命名方案新增默认关闭的“智能画面校正”；CLI 使用 `--auto-enhance`，MCP 使用同名布尔参数。
- 可审计、可复用：`clips.json` 记录采样数、亮度/饱和度测量、触发原因和精确调整；渲染缓存按派生方案区分，启用但无需调整的素材仍保留原有流复制路径。
- 超长录播有界：每秒证据超过 50,000 条时均匀保留完整源片首尾覆盖，索引始终可缓存、可清理、可重建。

验证：104 个测试文件全部通过，1,088 项通过、1 项按既有条件跳过；TypeScript 双目标检查、生产构建、真实捆绑 FFmpeg 元数据/校正方向烟测，以及中英文桌面出片面板和官网响应式验收均通过。

# HotClip v0.22.0 — Fix the picture only when the evidence says so

This release adds fully local, model-free adaptive picture finishing. It is off by default and applies only a hard-capped subtle correction when final retained frames provide enough evidence of clearly dark, flat, overexposed or oversaturated footage.

- Clip-local measurement: the existing 4fps Tier-0 decode now retains luma low/mean/high and saturation. Jump cuts and stitched clips evaluate only final kept source ranges instead of grading every clip from one recording-wide average.
- Restrained hard caps: brightness, contrast, saturation and gamma stay within narrow bounds. Healthy footage emits no filter, near-monochrome material is never force-coloured, and weak evidence leaves pixels untouched.
- Render-path parity: continuous cuts, jump cuts and cold-open windows each receive the corresponding plan after crop/scale and before captions/watermarks, keeping text and brand colours unchanged.
- Same capability everywhere: the desktop export panel and named schemes gain a default-off toggle; CLI exposes `--auto-enhance`, and MCP exposes the matching boolean option.
- Auditable and cache-safe: `clips.json` records sample count, luma/saturation measurements, reasons and exact adjustments. Render-cache identity includes the derived plan, while enabled-but-neutral footage keeps the existing stream-copy path.
- Bounded extreme recordings: evidence beyond 50,000 one-second samples is evenly reduced while preserving full-source endpoints, so the index remains reusable, clearable and rebuildable.

Verification: all 104 test files passed, with 1,088 passing tests and 1 existing conditional skip. Both TypeScript targets, the production build, real bundled-FFmpeg metadata/correction-direction smoke tests, and bilingual responsive QA for the desktop export panel and website passed.
