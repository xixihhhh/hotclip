# HotClip v0.32.0 — Issue 修复与模型选择

## 审阅台预览修复

- 多个视频消费同一素材时，主画面、竖屏裁切和审阅弹窗使用独立的媒体资源路径，避免 Chromium 共享媒体缓冲导致永久黑屏或无法拖动。
- 本地媒体协议显式传播读流错误，并在取消时释放文件句柄。
- 预览失败按真实 `MediaError.code` 展示诊断信息，不再把读流中断误报成格式不支持。

## 模型下拉选择修复

- 获取模型清单后显示明确可点击的原生下拉框。
- 手动输入仍然保留，可处理供应商未返回或用户自定义的模型 ID。

## Issue 状态

- 修复公开 Issue #11：审阅台本地 MP4 预览永久失败。
- 修复公开 Issue #13：模型清单获取后下拉选择无响应。
