# HotClip v0.33.0 — 时长、数量与无人值守品类

## 桌面切片更好控制

- 工作台右栏常驻「时长档」和「最多切片数量」，不用再去检测参数页找入口。
- 新增 **1–2 分钟（60–120 秒）**选段档位，适合完整的带货演示和讲解；保留原有三档时长。
- 可选最多 **1–12 条**候选，默认 6 条。数量会传入 AI 选段，并在复评后优先保留可发布的候选，避免前面的弱片占满名额、漏掉后面的好片。
- 修改参数后点击「重新检测」生效，不会自动重复调用 AI。数量是上限，质量不足时不会凑数；时长指源片选段，导出剪气口等处理后可能缩短。

## 自动化也能选直播品类

- CLI `clip` / `highlights` 新增 `--genre`、`--genre-custom`、`--clip-length`，复用桌面品类预设；非法品类会报错并列出可选项。
- 品类贯穿检测证据、选段判据和导出跳剪节奏；非空自定义文本覆盖内置判据。
- MCP `clip_video` / `detect_highlights` 对应支持 `genre`、`genreCustom`、`clipLength`、`maxClips`。
- 文件夹监听与 webhook 共享品类、时长和数量设置，启动时保存快照；失败或中断任务重试沿用原参数。

```bash
pnpm cli clip "直播回放.mp4" --genre shopping --clip-length extended --max-clips 10
pnpm cli highlights "游戏录播.mp4" --genre game --genre-custom "只选完整的翻盘过程" --json
```

修复 [#15](https://github.com/xixihhhh/hotclip/issues/15) 和 [#16](https://github.com/xixihhhh/hotclip/issues/16)。本地验证通过类型检查、正式构建和 1,292 项测试（1 项跳过），新增参数透传、候选数量、信号通道及监听任务设置回归覆盖。

macOS 延续 v0.32.1 的应用与嵌套二进制签名校验。首次启动说明见 [macOS 安装指南](https://github.com/xixihhhh/hotclip/blob/v0.33.0/docs/macos-install.md)；当前仍无 Apple 公证。

## English

- Always-visible clip length and maximum-count controls, including a new 60–120 second source-selection preset and a 1–12 candidate limit.
- The requested count now reaches AI nomination and final selection, prioritizing publishable candidates before restoring timeline order.
- CLI and MCP expose genre, custom criteria and duration; genre reaches both detection and export pacing.
- Folder/webhook automation snapshots selection settings and preserves them when retrying a task.
- Existing duration presets remain available. Candidate count is a maximum, and removing pauses can shorten the final export.
