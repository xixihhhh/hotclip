# HotClip v0.28.0 — 长稿更好剪，任务接着做

发布日期：2026-09-05

- **已有字幕直接剪**：导入原文 UTF-8 SRT / WebVTT，保留原句时间；无需重新识别即可纠错、搜索和文字选段。句内估时明确标记，导入后先进入审阅，不自动发起 AI 分析。桌面、CLI 和 MCP 均可使用。
- **本地转写支持续跑**：每完成一个识别窗口就保存结果，停止或重启后复用已完成进度；支持从头重来。音频逐窗口读入，桌面识别在独立工作线程运行，长录音不再整段占用 JS 内存。
- **长稿搜索与局部校准**：支持 Unicode 跨句搜索、高亮、快捷键定位和动态行高列表；勾选句子后先预览、试听原时间与新时间，再应用，支持撤销与重做。校准保留原文和句子边界。
- **可选 Qwen3 本地语音**：支持单独管理的 Qwen3-ASR 0.6B / 1.7B 服务，可加载 ForcedAligner 提供字词时间。连接检查展示实际模型、设备和对齐器状态，只接受回环地址。默认 SenseVoice 保持可用，不自动安装 Python 或启动服务。
- **字幕更容易读**：按文字类型调整阅读速度预设，合并合适的短行、延长可用显示时间；尊重相邻字幕、说话人与剪辑边界，不移动逐字高亮的语音时间。仍未解决的问题继续在质检里报告。
- **导出取消与文件保护**：准备、翻译、文案、多版包装和动态字幕阶段均接入取消；重复导出不会覆盖活动任务。常规剪切、跳剪、音频成片、合集和动态字幕编码成功后才替换目标文件，失败或取消的编码保留已有目标。此前完成的切片继续保留，取消后可直接重试。
- **细节修复**：仅导出 SRT 时保留所需逐字稿；手动多段选片严格遵守边界；纯静音片段不再误识别；Qwen 零时长字词保留文字并正确标记时间来源；导出整理阶段不会提前显示 100%。

验证：1,230 项测试通过，1 项既有条件跳过；类型检查和生产构建通过。覆盖真实 FFmpeg 编码、失败/取消保护、CLI/MCP、5,000 句编辑界面及真实 Electron 离屏字幕取消。macOS ARM64 CPU 实测 Qwen3-ASR 0.6B + ForcedAligner、SenseVoice 和 Paraformer；小规模合成中英文样例不代表整体识别质量，1.7B 与 GPU 路径未做性能验证。

安装默认引擎无需 Python；可选 Qwen3 服务的安装、语言范围、续跑、校准及评估方法见[使用指南](https://github.com/xixihhhh/hotclip/blob/v0.28.0/docs/local-speech.md)。输出保护以单次编码为单位，不是整批导出的全部回滚。

# HotClip v0.28.0 — Edit long transcripts, resume interrupted work

Release date: 2026-09-05

- **Edit existing subtitles**: import original-language UTF-8 SRT / WebVTT with cue bounds preserved. Correct text, search and select passages without another ASR run. Estimated word timings stay visible; import opens review without automatic AI analysis. Desktop, CLI and MCP share the workflow.
- **Resume local transcription**: each completed recognition window is checkpointed. Stop, reopen and reuse completed work, or explicitly restart. PCM is read one window at a time, with desktop inference isolated in a worker.
- **Search and review long transcripts**: Unicode cross-sentence search, highlighted matches, keyboard navigation and dynamic-height virtualization. Preview selected timing corrections, listen before/after, apply, undo or redo while keeping the original text and cue boundaries.
- **Optional Qwen3 local speech**: connect a separately managed Qwen3-ASR 0.6B / 1.7B service with an optional ForcedAligner. Connection checks report the actual model, device and alignment capability. Only loopback addresses are accepted. SenseVoice remains the default; HotClip installs no Python runtime or starts a service automatically.
- **Readable caption pacing**: script-aware reading-speed presets, conservative short-line merging and display holds respect adjacent captions, speaker changes and edit boundaries without moving speech/karaoke times. Unresolved issues remain in the quality report.
- **Safer exports and cancellation**: preparation, translation, publish copy, variants and web captions share cancellation. A second desktop export cannot replace an active task. Cut, jump-cut, audiogram, compilation and overlay encoders replace the destination only after success; failed or cancelled encoding preserves the previous target. Previously completed clips remain available and retry keeps the selection.
- **Fixes**: SRT-only export retains its transcript, manual stitched selections keep exact bounds, digital silence no longer invents text, zero-duration Qwen words retain text with honest timing provenance, and finalization no longer reports completion early.

Verification: 1,230 tests passed with one existing conditional skip; typechecking and production builds passed. Real FFmpeg output/cancellation checks, CLI/MCP, a 5,000-cue interface and real Electron offscreen cancellation were exercised. Qwen3-ASR 0.6B + ForcedAligner, SenseVoice and Paraformer ran on macOS ARM64 CPU. Small synthesized Chinese/English fixtures do not establish general accuracy; 1.7B and GPU performance were not benchmarked.

Default engines need no Python. See the [optional speech guide](https://github.com/xixihhhh/hotclip/blob/v0.28.0/docs/local-speech.md) for setup, languages, recovery, alignment and evaluation. File protection applies per encoding operation, not as an all-or-nothing batch rollback.
