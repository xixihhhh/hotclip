# HotClip v0.34.0

## 中文

- **主播与游戏分屏**。导入录播后，在工作台预览区勾选「主播与游戏分屏」，调整水平位置、垂直位置和取景宽度。上方放大主播，下方保留完整游戏画面。默认继续使用原来的裁切模式。
- **品牌标题样式**。在「设置 → 品牌样式 → 品牌样式模板」选择经典底板、白字描边或品牌色底板。顶部标题开启后，预览中的样式会随成片导出。旧预设使用经典底板。
- **Kimi 高光检测**。文本和视觉请求使用 Kimi 模型的默认采样温度，解决固定温度模型返回 HTTP 400 的问题。
- **本地视觉恢复**。本机视觉服务返回空内容或无法解析的九宫格结果时，HotClip 在原时限内尝试一次结构化动作识别。恢复模式只把同一张接触表内从平静或普通手势变为明显动作的画格记为候选视觉峰值。它不提取屏幕文字。若本机模型给整张表的相同静态标题统一高分，同时每格又明确写着没有动作，保留屏显文字并降低动作分数。若服务不支持结构化格式，继续使用其他证据。远端服务沿用原请求方式。

## English

- Enable **Streamer + gameplay** in the workbench preview and adjust the camera centre and width. A close-up of the streamer appears above the full game. The existing crop stays the default.
- Open **Settings → Brand style** to choose a classic plate, outlined white text, or a plate in your brand colour. Preview the title before exporting. Existing presets retain the classic look.
- Highlight detection uses the Kimi model's default sampling temperature for text and vision, fixing HTTP 400 errors on fixed-temperature models.
- An empty or malformed contact-sheet reply from a loopback vision endpoint gets one constrained action-analysis retry within the existing deadline. Only a transition from low activity to a strong action within the sheet can create a recovered visual peak. Recovery does not supply OCR. A fully repeated local static title with identical text and an explicit no-action description keeps its text evidence without becoming a motion peak. Unsupported local servers fall back to the other evidence, and remote endpoints keep their existing request behavior.
