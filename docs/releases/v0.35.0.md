# HotClip v0.35.0

## 中文

- 在工作台打开「全部选项 → 下一期栏目配方」，保存当前品牌快照、字幕、分屏、导出和选段设置。可以指定开场、主体、收尾的目标秒数，也可以从当前切片读取。三段以上取首段、主体各段合计、末段；连续或两段切片按 20% / 60% / 20% 提供可编辑初值。
- 在导入页或工作台选择配方，点击「选新素材做下一期」。新工程从这期素材重新转写和选段。三段时间是选段目标，素材和质量门决定能否选出合适的段落。现有栏目切换时可点「应用到本期」，再重新检测。
- 可以把栏目导出为 `.hotclip.json`。文件保存配方与音频、Logo 的文件名。新机器应用时会让你绑定本地文件；取消绑定会保留当前设置。既有「出片方案」仍可使用。[试用周更示例](../recipes/weekly-recap.hotclip.json)。
- 开启「剪映草稿」和标题或字幕后，每条草稿会带独立可编辑文本轨。文字内容、换行与时间来自实际字幕事件，跟随跳剪、选段拼接、成功的前置片和修复裁边。文字可改，动态逐字效果、混音及追踪构图仍以渲染的 MP4 为准。
- CMX3600 的 29.97 NDF 时间码按源帧率计帧。长录播和多段拼接的源、目标时间码保持帧级连续。

## English

Save the active brand, captions, split layout, export choices and highlight criteria under **All options → Next episode recipes**. Set opening/body/ending targets in seconds, or use the current cut to fill them. Choose a new source for a clean project and fresh selections. Export a portable `.hotclip.json` and bind the named music and logo on the receiving machine. Older export schemes still work. [Try the weekly recap recipe](../recipes/weekly-recap.hotclip.json).

Jianying drafts now include editable text tracks for enabled titles and captions, following the actual rendered events and splice times. Animated word effects and tracked framing remain render features. CMX3600 exports now use the actual source frame rate for non-drop timecodes and accumulate record time in frames.
