# HotClip v0.16.0 — 工程留得住，每一步都能回头

这一版把 HotClip 从“完成一次切片任务”推进到可长期使用的本地创作工作区，并把一片多版与真实发布指标连接成谨慎的本地实验闭环。

## 新功能

- **项目工作区**：管理多份剪辑工程，支持切换、重命名、关闭、删除与媒体重连。源素材离线或发生变化时保留工程状态；删除工程不会删除源媒体。旧版活动会话会自动迁移。
- **可逆编辑历史**：选片、标题/切点、多片段调整、手动加片和逐句稿纠错统一支持撤销/重做。历史限制为 60 步 / 4 MB，并随项目安全恢复；损坏或超限历史不会阻止项目打开。
- **专业快捷键**：`Cmd/Ctrl+Z` 撤销、`Shift+Cmd/Ctrl+Z` 或 `Ctrl+Y` 重做；`Space/K` 播放暂停、`J/L` 前后 5 秒、`I/O` 设入出点、`[/]` 切换候选。输入框、按钮焦点和弹窗中自动让出原生操作。
- **本地 A/B 实验中心**：一片多版按源候选、导出批次和平台自动建组，通过稳定内容 ID 关联回填指标。只有同平台、72 小时内发布、每版至少 500 播放且数据完整时才给方向性判断；跨平台、缺时间、低样本、版本不全或歧义数据都会明确显示为证据不足。

## 稳定性与兼容

- 项目索引和工程正文分离、原子写入，支持损坏索引重建与源文件指纹检查。
- 可逆历史字段向后兼容 v0.15.x 工程；自动转写和重新检测会建立新基线，不污染人工编辑历史。
- A/B 实验只保存本地内容元数据与指标，不保存账号凭据，不声称多变量包装实验具有单因素因果关系。

## 下载说明

- Windows：安装版 `.exe` 或绿色版 `.zip`
- macOS Apple Silicon：`.dmg`
- Linux（实验性）：`.AppImage`

当前安装包尚未代码签名。Windows SmartScreen 请使用“更多信息 → 仍要运行”；macOS 首次打开请右键选择“打开”。

# HotClip v0.16.0 — Persistent projects, reversible edits

This release turns HotClip from a one-off clipping flow into a persistent local project workspace, then connects multi-version exports to real post metrics through a conservative local experiment loop.

## Highlights

- **Project workspace**: manage multiple edits with switch, rename, close, delete and media relinking. Offline or changed source media keeps its project state; deleting a project never deletes source media. Legacy active sessions migrate automatically.
- **Reversible edit history**: selection, copy/boundaries, multi-piece adjustments, manual clips and transcript corrections share undo/redo. History is capped at 60 commands / 4 MB and restored with the project; corrupt or oversized history never blocks project recovery.
- **Professional shortcuts**: `Cmd/Ctrl+Z` undo, `Shift+Cmd/Ctrl+Z` or `Ctrl+Y` redo; `Space/K` play, `J/L` ±5 seconds, `I/O` in/out, and `[/]` candidate navigation. Inputs, focused controls and modals retain their native behavior.
- **Local A/B experiment center**: multi-version exports group by source candidate, export batch and platform, then join imported metrics through stable content IDs. A direction appears only for complete same-platform groups published within 72 hours with at least 500 views per version; platform mismatch, missing dates, low samples, incomplete groups and ambiguous data stay explicit.

## Reliability and compatibility

- Split, atomic project index/documents with corrupt-index rebuilds and source fingerprint checks.
- Edit-history fields are backward-compatible with v0.15.x projects; automatic transcription and re-detection establish a clean baseline instead of entering human history.
- Experiments store local content metadata and metrics only—never account credentials—and multi-variable packaging tests are never presented as single-variable causation.
