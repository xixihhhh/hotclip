常见问题

HotClip 是免费的吗?

是。开源(AGPL-3.0)、本地运行、无水印、无积分制、不限时长。可选的云端大模型按你自己的 Key 计费,接本机 Ollama 则完全免费。

和 OpusClip、剪映切片有什么区别?

最大区别是素材不出你的电脑:OpusClip 等必须上传云端、按源视频分钟扣积分(月底清零),免费档带水印;剪映切片核心功能在会员里。HotClip 免费开源、本地处理、无水印、不限时长,AI 切点附理由可审计。

需要联网吗?

转写、字幕、切片、导出全程离线。只有「AI 找爆点」默认调云端大模型(你自己的 Key);接本机 Ollama 后整条流水线 100% 离线。

支持中文视频吗?

支持且是强项:SenseVoice / Paraformer / FireRedASR2 专用引擎,方言、粤语、中英混说覆盖;界面、字幕、提示词都为中文内容适配。

需要显卡吗?

不需要。本地转写用 int8 量化小模型,普通 CPU 就能跑。

可以商用/切别人的直播吗?

HotClip 面向你自己的内容或已获授权的切片(如主播切片授权计划)。未经授权的影视/直播搬运不受支持,也不欢迎。
